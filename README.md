# تأجير السيارات — Car Rental System

نظام تأجير سيارات مبني بـ Next.js (App Router) + TypeScript + Prisma/SQLite + NextAuth. يعرض السيارات المتاحة، يتيح للعميل حجز سيارة بتواريخ محددة (مع منع تعارض الحجوزات)، ويوفر لوحة تحكم للإدارة لإضافة/تعديل/حذف السيارات ومتابعة كل الحجوزات.

## التشغيل محليًا

```bash
npm install
npx prisma migrate dev   # ينشئ قاعدة بيانات SQLite محلية (prisma/dev.db)
npx prisma db seed       # يضيف بيانات تجريبية: سيارات + حساب أدمن + حساب عميل
npm run dev
```

افتح http://localhost:3000

### حسابات تجريبية (من الـ seed)

| الدور | البريد | كلمة المرور |
|---|---|---|
| أدمن | admin@example.com | admin123 |
| عميل | customer@example.com | customer123 |

## رحلة المستخدم

`/` (صفحة بحث بالفلاتر: المدينة، نوع السيارة، الغرض من الاستخدام، عدد الركاب، نطاق السعر، التواريخ) ← `/cars` (نتائج مع نفس الفلاتر قابلة للتعديل، ويستثني تلقائيًا أي سيارة محجوزة بالكامل خلال التواريخ المختارة) ← `/cars/[id]` (تفاصيل السيارة + تقويم التوفر + الحجز).

## البنية

- `app/` — الصفحات العامة، صفحات العميل (`my-bookings`)، ولوحة الأدمن (`admin/`)، وكل الـ API تحت `app/api/`.
- `lib/auth.ts` — إعداد NextAuth (Credentials + جلسات JWT بالدور CUSTOMER/ADMIN).
- `lib/carOptions.ts` — القيم الثابتة المشتركة: نوع السيارة (category)، ناقل الحركة، نوع الوقود، والغرض من الاستخدام مع تعيينها الافتراضي لنوع السيارة/عدد المقاعد.
- `lib/carFilters.ts` — منطق بناء فلتر البحث عن السيارات (المدينة، النوع، السعر، الركاب، وتوفر التواريخ) المستخدم في كل من صفحة `/cars` و`/api/cars`.
- `lib/dateRanges.ts` — منطق التحقق من تعارض التواريخ (يعمل بتوقيت UTC دائمًا لتفادي مشاكل فروقات التوقيت بين السيرفر والمتصفح).
- `lib/clientDates.ts` — نفس منطق التواريخ لكن للواجهة (المتصفح)، بحيث يتطابق اليوم الذي يختاره المستخدم مع اليوم الذي يُرسل للسيرفر بغض النظر عن المنطقة الزمنية.
- `prisma/schema.prisma` — نماذج User / Car / CarImage / Booking.
- `prisma/seed.ts` — بيانات تجريبية.
